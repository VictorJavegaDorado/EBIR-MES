# Instrucciones de Infrastructure

- Usa consultas o procedimientos concretos para cada caso de uso.
- Todas las conexiones deben apuntar explícitamente a `EBIR_MES_TEST`.
- No construyas nombres de base dinámicos ni consultes catálogos de otras bases.
- Configura tiempos de espera, cancelación y traducción segura de errores.
- Las transacciones pertenecen a una operación de negocio concreta.
