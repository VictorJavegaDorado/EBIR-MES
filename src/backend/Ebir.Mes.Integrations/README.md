# Integraciones

`Navision` contiene el adaptador SOAP de lectura de cabeceras, líneas, ruta y
componentes de órdenes de producción. No queda registrado en ningún proceso
durante esta fase y sus pruebas utilizan respuestas sintéticas.

Las carpetas `Printing` y `Rfid` se crearán cuando un caso de uso necesite cada
límite. Hasta una autorización explícita, todas las validaciones utilizarán
dobles de prueba y no equipos reales.
