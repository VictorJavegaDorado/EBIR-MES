# Glosario de dominio

- **Línea**: puesto físico de fabricación sobre el que se abre una sesión.
- **Sesión de línea**: periodo operativo asociado a una línea, fecha y turno.
- **Turno**: `MANANA` (06:00–14:00) o `TARDE` (14:00–22:00), con la extensión
  horaria definida en las reglas de negocio.
- **Fichaje productivo**: entrada o salida de un empleado en una sesión.
- **Orden**: orden de producción importada o contrastada con NAV.
- **Palé**: agrupación trazable de unidades producidas.
- **Scrap**: material descartado que debe registrarse y, cuando proceda,
  revisarse.
- **Reaprovisionamiento**: solicitud de material originada en planta.
- **Trabajo de impresión**: petición persistida y procesada de forma asíncrona.
- **Supervisor**: perfil autorizado para excepciones y correcciones auditadas.
