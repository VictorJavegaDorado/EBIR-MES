# Referencia heredada

Esta carpeta reserva la ubicación de material histórico. No forma parte de
`Ebir.Mes.sln`, no se despliega y no debe usarse como origen de secretos o
configuración.

La prueba de concepto Node/Express y los documentos anteriores permanecen por
ahora únicamente en el equipo de origen. Antes de incorporarlos al servidor se
deben revisar y eliminar configuraciones, credenciales, endpoints y datos que
no deban versionarse.
